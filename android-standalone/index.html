KONEKSI MODEL

Pengaturan AI

Mode Gratis Lokal aktif secara default.

Di APK Android, API key disimpan terenkripsi memakai Android Keystore. Mode browser/preview hanya menyimpan key di memori sesi dan tidak menyimpannya di localStorage. Tetap lindungi perangkatmu dan jangan commit API key ke GitHub.

OpenRouter: model gratis dipilih otomatis lewat openrouter/free. Kuota dan ketersediaan mengikuti OpenRouter.

Fallback nonaktif secara default. Jika diaktifkan, aplikasi mencoba provider tersimpan lain yang punya konfigurasi dan kredensial valid. Benchmark dan uji koneksi tetap hanya memakai provider yang dipilih.

Benchmark menjalankan satu permintaan singkat ke provider yang tersimpan; penggunaan API dapat memakai kuota/biaya.

Belum ada provider diuji.

Mode API memerlukan internet dan API key untuk provider cloud. Untuk OpenRouter gratis, gunakan model openrouter/free atau ID model berakhiran :free; model berbayar bisa menghabiskan kredit. Kuota gratis dibatasi dan model dapat sementara tidak tersedia. Endpoint custom tanpa key hanya untuk server lokal/tepercaya. Mode Gratis Lokal di atas tidak memerlukan API key, tetapi saat ini adalah asisten berbasis aturan, bukan LLM generatif.
