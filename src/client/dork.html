Google Dorking Workbench

Bangun query pencarian yang dapat direproduksi. Hasil berasal dari Google; halaman ini tidak mengklaim bahwa hasil pencarian adalah kerentanan terkonfirmasi.

Target dan pola pencarian

Gunakan domain yang kamu miliki atau punya izin untuk diperiksa. Query hanya mencari indeks publik; jangan mengakses atau mengunduh data sensitif yang ditemukan.

Query siap digunakan

Pilih “Cari di Google” untuk membuka query pada Google Search. Query yang dibuat tidak menjalankan scan aktif.

Isi preset lalu tekan Generate query.

Privasi: query dibuat di browser. Halaman ini tidak meminta API key dan tidak mengambil data dari target secara otomatis.
