Digital Forensics Workbench

Pemeriksaan awal berbasis berkas dan teks yang Anda pilih secara eksplisit. Tidak mencari seluruh perangkat, mengakses akun, atau mengambil data tersembunyi.

Chain of custody: gunakan salinan kerja, catat asal dan waktu, pertahankan file asli, dan jangan menganggap hasil otomatis sebagai bukti final. Semua pemrosesan teks dan hash di halaman ini dilakukan lokal di browser.

Analisis teks / log / artefak

Tempel log atau teks yang memang berhak Anda analisis. Isi tidak diunggah. Pencocokan IOC bersifat heuristik dan dapat menghasilkan false positive/negative.

Catatan timeline

Browser tidak dapat membaca semua metadata filesystem, memulihkan file terhapus, atau memeriksa seluruh perangkat. Untuk forensik formal gunakan write blocker, image bit-per-bit, alat tervalidasi, dan prosedur hukum yang sesuai.
